# ICPC Sinchon Discord Bot (SUAPC)

ICPC Sinchon 운영을 자동화하기 위한 Discord 봇입니다. **출석 체크**와 **주차별 강의 링크 배포**를 담당합니다.

> [discord.js](https://discord.js.org/) 위에 얇게 직접 배선한 구조입니다. 프레임워크(Sapphire 등) 없이, 커맨드/이벤트를 폴더 규칙으로 로드합니다.

## 주요 기능

### 1. 자동 출석 체크 (Google Sheets 연동)

- **스케줄 관리**: 매일 지정된 시간에 음성 채널 입장을 자동으로 확인합니다.
  - **초급 (Novice)**: 오후 3시 15분 (`15:15`)
  - **중급 (Advanced)**: 오후 5시 15분 (`17:15`)
- **분반별 관리**: 각 분반 전용 음성 채널 인원만 확인합니다.
- **시트 자동 업데이트**: 오늘 날짜(`YYYY.M.D`) 컬럼을 찾아 출석 시 `1`, 결석 시 `0`을 기록합니다.
- **자동 보고**: 출석 체크 후 지정된 텍스트 채널로 출석 현황(임베드)을 전송합니다.
- **on/off 토글**: `/출석` 명령어로 자동 체크를 켜고 끌 수 있습니다.

### 2. 분반 역할 자동 부여 (지원 폼 연동)

- `/역할버튼` 으로 채널에 "역할 부여받기" 버튼을 게시합니다. (관리자)
- 수강생이 닉네임을 **`이름(id) 소속`** 형식으로 설정하고 버튼을 누르면, 봇이 **지원 구글폼**에서 그 사람의 신청 분반을 찾아 **초급/중급 역할을 자동 부여**합니다.
  - 닉네임의 이름(+id=solved.ac 핸들)으로 폼과 매칭, 동명이인은 id로 구분
  - 형식 불일치·미신청·동명이인 등은 안내 메시지로 반려
- ⚠️ 봇에 **"역할 관리" 권한**이 있어야 하고, 봇 역할이 초급/중급 역할보다 **위**에 있어야 부여됩니다.
- ⚠️ 폼 조회는 시즌 규격에 의존합니다 → 폼이 바뀌면 [forms.ts](src/lib/forms.ts)의 열 탐지를 확인하세요.

### 3. 주차별 강의 링크 배포

- 분반(초급/중급)별·주차별 강의 영상 링크는 **`링크` 탭에 직접 입력**합니다. (운영진)
- `/강의버튼` 으로 채널에 주차 선택 드롭다운을 게시합니다. (관리자)
- 수강생이 드롭다운에서 주차를 고르고 확인 버튼을 누르면, 봇이 **수강생의 역할(초급/중급)을 자동으로 판별**해 해당 분반 링크를 **DM으로** 전송합니다.
- **수강권(횟수 제한)**: 학생마다 남은 수강권(강의 받을 수 있는 횟수)을 `출결` 시트 `수강권` 열에서 관리합니다. 강의를 받을 때마다 **1 차감**되고, 남은 개수를 안내합니다. `0`이면 거절합니다. 운영진이 사람마다 이 숫자를 직접 조절합니다.

## 명령어

모두 **관리자 전용**입니다.

| 명령어 | 설명 |
| --- | --- |
| `/출석` | 자동 출석 체크 on/off |
| `/역할버튼` | 닉네임 확인 후 신청 분반(초급/중급) 역할 자동 부여 버튼 게시 |
| `/강의버튼` | 강의 선택 드롭다운 게시 |
| `/명단동기화` | 초급/중급 역할 멤버를 `출결` 시트 명단에 동기화 |

## 프로젝트 구조

봇 전체의 배선은 `index.ts` + `commands/index.ts` 두 파일만 읽으면 파악됩니다. (동적 로딩·프레임워크 magic 없음)

```text
src/
├─ index.ts               # 진입점: 클라이언트 생성 → 이벤트 연결 → 로그인 → 슬래시 명령어 등록
├─ interactions.ts        # 인터랙션 라우터 (명령어 / 드롭다운 / 버튼)
├─ types.d.ts             # ProcessEnv 타입
├─ commands/
│  ├─ index.ts            # ★ 모든 명령어를 나열하는 곳 (배열 + 이름→명령어 Map)
│  ├─ attendance.ts       # 각 명령어 = export default { data, execute }
│  ├─ lecture-board.ts
│  ├─ role-board.ts       # /역할버튼
│  └─ roster-sync.ts      # /명단동기화
└─ lib/
   ├─ sheets.ts           # creds.json 서비스 계정 인증
   ├─ roster.ts           # 출결 시트 명단 동기화 + 수강권 카운터
   ├─ forms.ts            # 지원 폼 조회 (역할버튼 분반 판별, 시즌 규격 의존)
   ├─ role-components.ts  # 역할 부여 버튼 UI + 핸들러
   ├─ attendance.ts       # 출석 로직 + cron 스케줄 (출결 시트)
   ├─ lecture-links.ts    # 강의 링크 시트(링크 탭) 읽기
   └─ lecture-components.ts  # 드롭다운/버튼 UI + 핸들러
```

### 새 명령어 추가하기

1. `src/commands/<이름>.ts` 파일을 만들고 `export default { data, execute }` 형태로 작성합니다.
2. `src/commands/index.ts`의 `commands` 배열에 import해서 추가합니다. (배선이 한 곳에 다 모여 있음)

## 설치 및 설정

### 필수 요구 사항

- [Bun](https://bun.sh/) 런타임
- Google API 서비스 계정 JSON 키 (`creds.json` 을 프로젝트 루트에 배치)
- Google Sheets (수강생 이름 및 핸들 정보 포함)

### 환경 변수

`.env.example` 을 `.env` 로 복사한 뒤 값을 채웁니다.

```bash
cp .env.example .env
```

| 변수 | 설명 |
| --- | --- |
| `DISCORD_TOKEN` | 봇 토큰 |
| `GUILD_ID` | 봇이 동작할 서버 ID (슬래시 명령어가 이 길드에 등록됨) |
| `SPREADSHEET_ID` | 출석 현황 스프레드시트 ID |
| `NOVICE_CHANNEL_ID` / `NOVICE_VOICE_CHANNEL_ID` | 초급 보고 텍스트 / 확인 음성 채널 |
| `ADVANCED_CHANNEL_ID` / `ADVANCED_VOICE_CHANNEL_ID` | 중급 보고 텍스트 / 확인 음성 채널 |
| `NOVICE_ROLE_ID` / `ADVANCED_ROLE_ID` | 초급 / 중급 수강생 역할 (강의 링크 분반 판별 + `/역할버튼` 부여 대상) |
| `FORM_INTERNAL_ID` / `FORM_EXTERNAL_ID` | 내부인/외부인 지원 구글폼 응답 시트 ID (`/역할버튼`용, 서비스계정에 공유 필요) |

### 실행

```bash
bun install       # 의존성 설치
bun run dev       # 개발 (파일 변경 시 자동 재시작)
bun start         # 실행
```

Docker로 실행하려면 (루트에 `creds.json`, `.env` 준비):

```bash
docker compose up -d --build
```

## 시트 구성 가이드

### 출결 탭 (학생 명단 + 출석 + 수강권)

학생 명단·출석·수강권을 **`출결` 시트 한 곳**에서 관리합니다. **유저ID가 유일 키**입니다.

- **`유저ID`**: 학생 식별 키. (텍스트 서식) `/명단동기화`가 초급/중급 역할 멤버를 `유저ID/이름/수강난이도`로 채웁니다. → 운영진이 ID를 손으로 넣을 필요 없음.
- **`이름` / `수강난이도`**: 봇이 역할에서 채웁니다. (`초급`/`중급`)
- **`수강권`**: 그 학생이 남은 강의 횟수. **운영진이 사람마다 이 숫자를 직접 지정**합니다. 강의를 받을 때마다 봇이 1씩 차감하고, `0`(또는 빈 칸)이면 거절합니다. 명단에 없던 학생이 요청하면 수강권을 빈 칸으로 두고 행만 추가하니, 운영진이 값을 채워주세요.
- **수업 날짜 열**(구글 시트 날짜 형식): 오늘 날짜와 일치하는 열에 출석 `1`/결석 `0`이 기록됩니다. 사람이 미리 수업 일정 열을 만들어 두세요. 출석 판정은 **음성 채널 접속자를 유저ID로 대조**합니다.

- 이번 시즌 지원 구글폼 등 외부 데이터로 명단을 초기 세팅하고 싶으면, 그 시즌 규격에 맞춘 일회성 스크립트로 처리하세요. (폼 규격은 시즌마다 달라지므로 봇 코드에 넣지 않습니다.)

> `합계` 등 사람이 만든 수식 열은 봇이 건드리지 않습니다. 봇이 새로 추가한 학생 행에는 수식이 없으니 필요하면 아래로 채워주세요. 오늘이 수업 날짜 열에 없으면(수업일 아님) 출석은 기록하지 않습니다.

### 링크 탭 (강의 링크)

강의 링크는 **`링크` 탭**에 `분반 / 주차 / 링크` 컬럼으로 저장됩니다. 현재 초급/중급 × 1~10주차 그리드가 미리 채워져 있으니, **운영진이 각 행의 `링크` 칸에 URL을 직접 붙여넣으면** 됩니다. `분반` 값은 `초급` / `중급` 이고, 쓰지 않는 주차 행은 비워두거나 삭제해도 됩니다.
